## 为什么需要你手动下载

已尝试自动下载，全部失败，原因是 Pixabay 的访问保护：

| 方式 | 结果 |
|---|---|
| `curl` 抓网页 | HTTP **403**（Cloudflare 拦截） |
| Pixabay CDN 直链 | HTTP **403** |
| 本机 yt-dlp | 未安装 |
| Pixabay 官方 API | **只开放图片和视频，不含音乐** |

绕过 Cloudflare 会违反对方服务条款，且 Pixabay 下载音频通常需要登录态，所以这一步交由你完成。
（其余环节我都能代劳：转码、无缝循环、音量归一、接入 App。）

## 挑曲标准（针对拉伸场景）

- 无鼓点、无强节奏（BPM 60–80）——有节奏会干扰呼吸配合
- 无人声（或纯哼唱无歌词）——有歌词会抢注意力
- 时长 **1:40 – 3:30** 最佳：太短循环太频繁，太长文件体积大
- 优先选标签含 Calm / Soft / Relax / Ambient / Peaceful 的
- 已避开 "Sad"、"Drama"、"Techno"、"Beats" 等情绪过强或有节拍的

## 你的操作步骤

1. 点开上面任一链接，页面里有试听播放器，**先听 30 秒**（重点听：有没有突然进来的鼓点？结尾是不是拖长淡出？）
2. 满意就点页面上的 **Download** 按钮下载（可能要求登录 Pixabay 账号）
3. 把下载到的文件放进本目录：`artifacts/music-candidates/`
4. 文件名保持原样即可，不用重命名

**建议先下载你最有感觉的 3–5 首**，不必一次凑满 10 首——我处理完第一批你听效果，再定要不要第二批。

## 下载后我会做什么

1. **转码**：统一转 44.1kHz mp3（128kbps）——现在的音效都是 wav，60 秒 wav ≈ 5.3MB，轻音乐必须压；APK 现 79.8MB，加 3 首约 +2MB
2. **无缝循环**：首尾交叉淡化处理，避免每 2 分钟"咔"一下断掉
3. **音量归一**：背景音当前固定压到 50%，会确保它不盖过提醒音（提醒音的 duckOthers 优先级更高）
4. **接入 App**：加进 `constants.ts` 的 `BACKGROUND_SOUNDS`、设置页加"轻音乐"分组、同步 `spec.md` F3
5. **重新打包**：出新 APK（版本建议 1.4.0）
