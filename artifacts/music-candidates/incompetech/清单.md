## 筛选口径

从 1442 首里程序化筛出，条件：

- **情绪**：feel 含 calm / relax / peace / gentle / serene / tranquil / soft / dream / quiet
- **排除情绪**：somber / dark / eerie / sad / mysterious / unnerving / ominous（拉伸时听忧郁的曲子很别扭）
- **排除乐器**：drums / percussion / beat / tympani / brass / horn / trombone / trumpet（鼓点干扰呼吸节奏；铜管太雄壮）
- **BPM ≤ 75**（呼吸配合；拉伸时 BPM 60 左右最舒适）
- **时长 90–240 秒**（太短循环频繁，太长没必要）

1442 首 → 114 首（宽筛）→ 54 首（加严）→ **19 首**（排除忧郁+铜管+鼓点）→ 取前 10。

若这 10 首都不满意，**剩余 9 首随时可下**（脚本已就绪）。

## 几个特别说明

- **02 是巴赫《平均律》C 大调前奏曲**，纯钢琴、49bpm。古典曲目认知度高，但要注意有些用户会对熟悉旋律产生"听腻"感。
- **01 和 05 用的是 Koto（日本筝）**，音色清亮、有东方禅意，和"冥想/拉伸"场景很搭，但辨识度高，听多了可能出戏。
- **10 是《婚礼进行曲》钢琴版**，旋律辨识度极高（可能引起联想），建议优先试听再决定留不留。
- 全部 320kbps，**体积偏大（总 72MB）**。接入 App 时我会统一转 **128kbps**，10 首合计约 29MB；若只留 3 首则约 9MB。

## 处理结果（已做无缝循环 + 响度归一）

处理后的文件在 **`looped/`** 子目录，**试听请听这里的**（这才是最终形态；根目录是原始素材）。

处理内容：
1. **首尾交叉淡化 1.5s** —— 消除循环接缝的"咔"声（原理见 `RNApp/scripts/prepare-music.py` 头部注释）
2. **响度归一到 -18 LUFS**（EBU R128）+ 真峰值上限 -1.5 dBTP
3. **转码 128kbps 立体声**（原始 320kbps）

处理过程中发现并修掉的两个问题：

- **原始素材电平极不统一**：实测有的峰值 `-16.36 dBFS`、有的 `+0.46 dBFS`（已削波）。不归一的话切歌会忽大忽小。
- **简易 RMS 归一不够**：这批是无损母带，动态范围大（峰值因子 17–23dB），按 RMS 提增益会被峰值顶住，7 首被迫让步、与达标的差 5.5dB。改用 ffmpeg `loudnorm`（按人耳感知响度）后，**差异压到 2.4dB**。

实测验证（随机抽 3 首）：

| 文件 | 集成响度 | 真峰值 |
|---|---|---|
| 01-Senbazuru | -18.0 LUFS | -3.5 dBTP |
| 04-Reawakening | -17.5 LUFS | -1.8 dBTP |
| 09-Last_Kiss_Goodnight | -18.4 LUFS | -2.4 dBTP |

（处理后 RMS 看起来"变小"是正常的：LUFS 是 K 计权感知响度，与裸 RMS 不是同一标尺。关键是**各曲之间的差异**从 5.5dB 收窄到 2.4dB，且峰值全部安全。）
