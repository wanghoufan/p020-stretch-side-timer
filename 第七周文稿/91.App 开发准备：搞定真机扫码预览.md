再往前走一步把APP真正运行到自己的手机上具体来说我们会用到Expo Go 通过扫码把电脑上的项目连接到手机这样以后每次修改代码我们都可以直接在真实的iPhone 或安卓手机上查看效果也更方便确认界面自体触感以及不同设备上的实际表现要在iPhone上进行真机预览我们首先需要安装手机端的Expo Go 不过这里有一个比较容易踩的坑不要直接去App Store 搜索Expo Go下载因为每个版本的Expo Go 都只支持对应的Expo SDK 如果手机上的Expo Go 和我们项目用的SDK对不上打开项目时就可能提示版本不兼容那正确的做法是我们来到Zine.Expo.

dev 然后从这个网站上安装版本匹配的Expo Go 这里我们跟着页面指引一步步操作就可以第一步选择SDK版本这里要和我们项目的版本保持一致比如我们现在用的是SDK57 那就选择SDK57 第二步登陆前面注册好的Expo账号第三步登陆Apple ID 这里主要是利用Apple提供的免费开发者签名

给接下来安装到这台iPhone上没有经过签名的App iPhone一般不允许直接安装和运行第四步注册我们要测试的iPhone设备网站提供了不同的设备连接方式二维码USB和手动注册这里我们可以用USB 先用数据线把iPhone连接到电脑然后点击Connect over USB 在浏览器弹出的设备列表里选择自己的手机点击连接网站就可以识别这台设备了接下来点击Continue到下一步第五步网站会根据我们刚才选择的SDK版本和设备信息给这个Expo Go完成签名那么我们点击Sign Expo Go 如果第一次没有成功我们就按照页面提示再重视一下签名完成以后点击Continue to Install 进入安装步骤第六步这里我们还是用USB安装点击Install over USB 然后在浏览器弹出的窗口里再次选择我们的iPhone 点击连接然后等待安装完成如果这里出现安装失败也不用担心可以先缺人Mac上的iPhone镜像已经完全退出然后把iPhone数据

线拔掉再重新插上再次点击Install over USB 等队连接时备到设备以后在弹装里选择对应的iPhone 再点击连接重新成删装安装成功以后手机桌面就会出现Expo Go 我们第一次打开时可能会提示不受信任的开发者这时候还需要到系统设置里完成一次授权打开iPhone的设置进入通用VPN与设备管理在开发者App下面找到刚才对应的开发者账号点进去以后选择信任那在弹出的确认窗口里继续允许抽取完整以后再重新打开Expo Go 就可以正常使用了 Expo Go第一次打开时会先出现一个欢迎页和简单的小聊言这些内容和我们后面运行项目没有关系可以直接点击SK跳过然后点击Start First S and继续这里还会弹出一个提示告诉我们齿轮按钮是DevTooth 也就是开发者工具它主要用来做开发式的辅助操作比如重新加载当机项目打开开发者菜单查看调试相关信息等等我们现在先直接点击Continue 然后把Tooth的提示关掉这里会进入到新手课程页面我们

点击左上角的Go Back 就可以退出新手教程来到Expo Go的主页了那安卓这边的步骤就简单很多我们打开Expo.dev-go 先确认SDK version 选的是和项目一致的版本然后点击Android旁边的Install 进入对应版本的安卓下载页面接下来用安卓手机扫描页面上对应版本的2维码按照提示下载对应的APK安装包然后在手机上完成安装就可以了如果系统第一次组组安装了也不用担心这是因为APK不是从应用商店安装的我们按照手机提示允许安装位置应用或者允许来自此来源的应用再重新打开APK完成安装即可装好Expo.go以后我们回到电脑让Colex帮我们启动Expo的开发服务器然后申请扫码预览2维码提交以后 Colex会启动开发服务器正常情况下 Expo会在中端里申请扫一个2维码我们就可以用手机连接这个项目扫码之前先确认手机和电脑连接的是同一个WiFi 然后打开Expo.

go 点击Scan QR Code 扫描电脑上的2维码扫码以后手机会开始从电脑上的开发服务器加载项目代码和资源第一次打开可能会稍微等一会这是正常的加载完成以后我们就能在自在手机上看到刚刚那个APP页面了连上以后先别接着关接下来我们可以让Colex修改程序看看真机上的效果会怎么变化 Expo默认支持Fast Refresh 也就是说大部分进行赛只要代码保存完成
