### 2. resolveLanguage 实际执行

执行方式：Node.js 读取 `RNApp/src/i18n/index.tsx`，逐字提取 `FOLLOWABLE_CODES` 初始化语句与 `resolveLanguage` 函数体，使用项目安装的 TypeScript `transpile` 编译后在 Node VM 中执行；无临时文件。提取源码与源文件比对：**一致**。

```text
system + zh-Hans-CN => zh
system + en-US      => en
system + ja-JP      => zh
system + zh         => zh
system + en         => en
system + EN-us      => en
system + zh_CN      => zh
system + null       => zh
system + undefined  => zh
system + ''         => zh
zh     + en-US      => zh
en     + zh-Hans-CN => en
```

实跑结论：中文系统得到中文；英文系统得到英文；日语系统回落中文；手动选择优先于系统 locale。

自动纳入新语言：`FOLLOWABLE_CODES` 在 `RNApp/src/i18n/index.tsx:55-57` 由 `LANGUAGES.map(...).filter(code !== 'system')` 推导。实跑时在该表模拟增加 `{ code: 'ja' }` 后，`system + ja-JP => ja`。因此加支持语言表项即可进入跟随解析候选，无需改解析函数。
